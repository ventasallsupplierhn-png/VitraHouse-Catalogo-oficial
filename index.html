Importar o actualizar inventario

Seleccione el reporte de inventario en formato .xlsx, .xls o .csv. La plantilla reconoce las columnas del archivo actual y conserva las ubicaciones que usted haya registrado.

También puede arrastrar el archivo a esta área.

Base inicial: 796 registros importados del archivo Inventario_Lotes.

Cómo funciona la actualización

Al importar una nueva base, el sistema usa Código + N.º de lote para identificar cada registro. La columna Ubicación / Estante se guarda en este navegador y se vuelve a aplicar automáticamente después de actualizar la base. En modo “Reemplazar” se toma el nuevo Excel como inventario vigente; en modo “Combinar” se actualizan coincidencias y se agregan registros nuevos.
